# Kentatsu Nobby Balance для Home Assistant

Пользовательская интеграция для котла Kentatsu Nobby Balance с ESP-15F. Home Assistant подключается по TCP к уже настроенному `stream_server` ESPHome, который передаёт кадры Midea между сетью и UART котла. Для работы достаточно Home Assistant и модуля ESP-15F.

## Установка через Marketplace

В Home Assistant 2026.11 и новее откройте **Настройки → Marketplace → Добавить по ссылке**. Подключите GitHub, если Home Assistant попросит, и вставьте URL этого публичного репозитория. Если Marketplace попросит выбрать тип, укажите **Интеграция**. Откройте карточку Kentatsu Nobby Balance, установите интеграцию и перезапустите Home Assistant.

Перед настройкой отключите HOMEd Custom Midea от этого ESP-15F. Затем откройте **Настройки → Устройства и службы → Добавить интеграцию → Kentatsu Nobby Balance**, введите адрес ESP-15F и порт `5678` или порт из вашего YAML.

Новые релизы появятся в **Настройки → Обновления**. На версиях Home Assistant с HACS добавьте этот же URL через **Пользовательские репозитории**, выбрав тип **Интеграция**.

## Ручная установка

1. Скопируйте папку `custom_components/nobby_balance` в `/config/custom_components/` Home Assistant. В результате должен появиться файл `/config/custom_components/nobby_balance/manifest.json`.
2. Перезапустите Home Assistant.
3. Закройте соединение HOMEd Custom Midea с этим ESP-15F перед добавлением интеграции, чтобы к UART через мост обращалась одна система.
4. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Kentatsu Nobby Balance**. Введите IP-адрес или имя ESP-15F и TCP-порт `5678` (или порт из вашего YAML). HA проверит, что за мостом отвечает котёл.
5. Откройте созданное устройство. Если у вас были автоматизации для сущностей из HOMEd, замените в них идентификаторы на новые.

Если действующая прошивка уже пробрасывает UART на порт `5678`, её можно использовать как есть. ESPHome в HA можно по-прежнему использовать для обслуживания модуля.

## Сущности

- Переключатели питания котла и отопления.
- Уставки температуры отопления (30–80 °C) и горячей воды (35–60 °C). Шаг 1 °C.
- Текущие температуры отопления и горячей воды, давление, пламя, режим работы и код ошибки протокола. Код протокола может отличаться от кода на дисплее котла.

Интеграция опрашивает котёл каждые пять секунд и восстанавливает TCP-соединение при следующем опросе после сбоя. Управление использует команды панели, описанные в исходнике HOMEd. HA обновляет состояние по телеметрии котла.
